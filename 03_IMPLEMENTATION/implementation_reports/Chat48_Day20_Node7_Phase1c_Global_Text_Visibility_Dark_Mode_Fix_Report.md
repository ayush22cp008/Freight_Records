## 3. Changes Made

### `src/app/globals.css`

Removed the conflicting `@media (prefers-color-scheme: dark)` block from the global CSS. Since the application components predominantly rely on explicit background and text utility classes (and deliberately enforce light themes for the main app surfaces), removing this media query allows the global default foreground to remain `#171717` (dark) globally. 

This successfully fixes readability for Driver and Company pages without negatively impacting the Reviewer portal, which utilizes explicit dark tailwind classes (e.g., `bg-gray-900`, `text-white`).
