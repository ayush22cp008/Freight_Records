- the production database/state for the exact failing public-share token, and

## 5. Important Diagnostic Rule
The shared helper currently returns `null` for a failed `trip_public_shares` lookup and for a failed trip lookup. Therefore an actual database/query condition may surface as a normal 404.

Do not classify `404` as proof of an invalid token until the database lookup itself has been verified.

## 7. Root-Cause Decision Gate
A root cause may be declared only after the database result, API result, and page/helper execution path agree.

Possible evidence-based outcomes include, but are not limited to:
- token/database mismatch;
- inactive/revoked share;
- missing referenced trip/data;
- database/query/environment failure being masked as 404;
- API/helper failure;
- page route resolution failure;
- deployed-source mismatch;
- another directly evidenced failure.

Do not choose among these until evidence identifies the actual branch.
